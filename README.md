# Интернет-магазин: товары и категории

Учебный проект по объектно-ориентированному программированию на Python. Разработан в рамках домашнего задания **14.1**: реализованы базовые сущности интернет-магазина — товары и категории товаров.

## Реализованная функциональность

### Класс `Product`

Описывает отдельный товар и хранит его характеристики:

- `name` (`str`) — название товара;
- `description` (`str`) — описание;
- `price` (`float`) — цена;
- `quantity` (`int`) — количество единиц на складе.

Все атрибуты инициализируются при создании объекта.

### Класс `Category`

Объединяет товары в категории и хранит:

- `name` (`str`) — название категории;
- `description` (`str`) — описание категории;
- `products` (`list[Product]`) — список объектов `Product`;
- `category_count` (`int`) — общее число созданных объектов `Category`;
- `product_count` (`int`) — суммарное число товаров в списках категорий на момент их создания.

`category_count` и `product_count` — **атрибуты класса**, общие для всех его экземпляров. Они обновляются автоматически при создании новой категории. `product_count` учитывает **число объектов в списке**, а не сумму их складских остатков (`quantity`). Изменение списка товаров после создания категории не обновляет счётчик автоматически.

## Пример использования

```python
from main import Category, Product

phone = Product(
    "Samsung Galaxy S23 Ultra",
    "256GB, Серый цвет, 200MP камера",
    180000.0,
    5,
)

smartphones = Category(
    "Смартфоны",
    "Смартфоны для коммуникации и удобства жизни",
    [phone],
)

print(phone.name)                 # Samsung Galaxy S23 Ultra
print(smartphones.name)           # Смартфоны
print(len(smartphones.products))  # 1
print(Category.category_count)   # 1 (если ранее категории не создавались)
print(Category.product_count)    # 1 (если ранее категории не создавались)
```

В `main.py` также находится демонстрационный блок `if __name__ == "__main__":`, который создаёт несколько товаров и категорий и выводит их характеристики.

## Установка и запуск

Для работы необходим Python с поддержкой встроенных обобщённых типов (`list[Product]`, Python 3.9+) и менеджер зависимостей [Poetry](https://python-poetry.org/).

Из корневой директории проекта выполните:

```powershell
poetry install
poetry run python main.py
```

## Тестирование

Для автоматического тестирования используется **pytest**. В `tests/test_main.py` реализованы проверки:

1. Корректной инициализации объекта `Product`.
2. Корректной инициализации объекта `Category`.
3. Подсчёта количества товаров (`Category.product_count`).
4. Подсчёта количества категорий (`Category.category_count`).

Перед тестами счётчики сбрасываются через фикстуру `pytest`, чтобы результаты не зависели от порядка выполнения тестов.

Запуск тестов:

```powershell
poetry run pytest -v
```

### Покрытие кода

Для анализа покрытия используется **pytest-cov**:

```powershell
poetry run pytest --cov=main --cov-report=term-missing --cov-report=html
```

HTML-отчёт формируется в `htmlcov/index.html`. В `main.py` демонстрационный блок запуска исключён из расчёта покрытия с помощью `# pragma: no cover`.

Целевое покрытие функционального кода по условиям задания — **более 75%**. Фактический результат определяется после запуска команды.

### Проверка качества кода

Проверка стиля с помощью **flake8** и аннотаций типов с помощью **mypy**:

```powershell
poetry run flake8 main.py tests
poetry run mypy main.py tests
```
